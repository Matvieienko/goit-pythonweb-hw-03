# goit-pythonweb-hw-03

Простий вебзастосунок, створений на основі вбудованих HTTP- та UDP-серверів Python.

## Функціональність

* маршрути для сторінок `index.html` та `message.html`;
* обробка статичних ресурсів `style.css` та `logo.png`;
* форма для надсилання повідомлень, яка передає необроблені байти на UDP-сервер;
* збереження повідомлень у форматі JSON у файлі `storage/data.json`;
* сторінка `/read`, створена з використанням шаблонізатора Jinja2;
* власна сторінка помилки `404 Not Found`;
* сервер доступний на порту `3000`;
* додаткова можливість запуску через Docker із постійним томом для збереження даних.

## Локальний запуск

Створіть віртуальне середовище:

```bash
python -m venv .venv
```

Активуйте віртуальне середовище у Windows:

```powershell
.venv\Scripts\Activate.ps1
```

Встановіть залежності та запустіть сервер:

```powershell
python -m pip install -r requirements.txt
python main.py
```

Відкрийте в браузері:

`http://localhost:3000`

## Запуск через Docker

```bash
docker compose up --build
```

Каталог `./storage` монтується в контейнер, тому збережені повідомлення залишаються доступними навіть після повторного створення контейнера.

## Тести

```powershell
python -m unittest discover -s tests -v
```
